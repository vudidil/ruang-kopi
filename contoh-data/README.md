# Data contoh untuk belajar

`backup-contoh-kedai.json` dibuat dari `RK.createPlan(true)` pada kode terbaru. Ini data buatan bawaan, bukan rencana atau transaksi pribadi pengguna. Hasil hitungan pasangannya ada di `bukti/hasil-hitung-contoh.json`.

Impor melalui Usaha saya → Simpan rencana. Impor biasa menambah rencana; gunakan profil browser pengujian bila tidak ingin menambah contoh pada data utama. Jangan menghapus localStorage.
